## 음성 호출 기반 스마트폰 찾기 앱 Android MVP

- 문서명: UX Flow & Screen Specification

- 작성일: 2026-02-15
- 기준 문서
- `docs/prd-voice-phone-finder-mvp.md`

## 2. UX 목표
1. 3탭 이내로 리스닝 활성화 가능해야 한다.
2. 분실 상황에서 시각적 조작 없이 음성 중심으로 회수 가능해야 한다.
3. 정책 제한(Android 14+ 백그라운드 제한, 권한 거부) 상황에서도 복구 경로가 명확해야 한다.

## 3. 사용자 플로우 맵

### 3.1 온보딩 플로우
1. 스플래시
2. 권한 안내(마이크/알림/진동)
3. 기본 키워드 설정
4. 리스닝 테스트
5. 홈 진입

### 3.2 핵심 찾기 플로우
1. 홈에서 리스닝 ON
2. 사용자 발화(웨이크 키워드)
3. 앱 `TRIGGERED` 전환
4. 3단계 사운드 재생
5. 사용자 `멈춰` 발화
6. 세션 종료 + 홈 복귀

### 3.3 설정 변경 플로우
1. 홈 -> 설정
2. 강제 재생/2단계 트리거/배터리 보호 변경
3. 저장 즉시 반영 배지 확인
4. 테스트 화면에서 검증

### 3.4 정책 제한 복구 플로우
1. 백그라운드 자동 시작 차단 감지
2. `READY_TO_RESUME` 알림 노출
3. 알림 액션 탭
4. 사용자 시작 컨텍스트로 리스닝 재개

## 5. 화면별 상세 명세

### S01 스플래시
목적:
- 앱 초기 상태 확인, 필수 스토리지/서비스 준비

컴포넌트:
- 앱 로고
- 로딩 인디케이터
- 초기화 실패 시 에러 카드

전이:
- 정상 -> S02(최초) 또는 S03(재실행)
- 실패 -> S09

### S02 권한 온보딩
목적:
- 필수 권한을 단계적으로 요청

컴포넌트:
- 권한 설명 카드 3개(마이크/알림/진동)
- `권한 허용` 버튼
- `나중에` 버튼 (필수 권한 미허용 시 제한 안내)

전이:
- 마이크 허용 -> 다음 단계
- 영구 거부 -> S09(설정 이동 CTA)

### S03 홈
목적:
- 리스닝 상태 관리와 즉시 상태 인지

컴포넌트:
- 리스닝 토글 스위치
- 상태 칩 (`IDLE`, `LISTENING`, `PENDING_CONFIRMATION`, `TRIGGERED`, `ERROR`)
- 배터리 보호 배지
- 마지막 세션 요약 카드(시각, 종료 사유)
- 빠른 액션 버튼: `테스트`, `키워드`, `설정`

상태별 UI:
- `LISTENING`: 녹색 칩 + 마이크 웨이브 애니메이션
- `TRIGGERED`: 빨간 강조 + 단계 진행 인디케이터
- `ERROR`: 주황 경고 + 복구 버튼

### S04 키워드 관리
목적:
- 웨이크 키워드/별칭 관리

컴포넌트:
- 키워드 리스트(최대 3)
- 추가/수정/삭제 버튼
- 유효성 검증 메시지
- 반영 상태 라벨(`엔진 반영 중`, `반영 완료`)

검증 규칙 UX:
- 길이/중복/금지어 위반 시 즉시 인라인 에러
- 저장 불가 시 버튼 비활성

### S05 설정
목적:
- 동작 정책 토글 관리

컴포넌트:
- 강제 재생 토글
- 2단계 트리거 토글
- 확인 문구 입력 필드
- 배터리 보호 토글 + 임계치 슬라이더
- 중지 문구 관리

상호작용:
- 변경 즉시 저장
- 실패 시 토글 롤백 + 에러 토스트

### S06 테스트/진단
목적:
- 사용자가 기능 동작을 사전 검증

컴포넌트:
- `키워드 테스트` 버튼
- `단계별 사운드 샘플` 버튼
- 권한 진단 카드
- 정책 진단 카드(Android 14+ 시작 제한 여부)

결과 표시:
- 성공: 초록 체크
- 실패: 코드 + 복구 가이드 링크

### S07 세션 로그
목적:
- 호출 히스토리 확인

컴포넌트:
- 세션 리스트(시간, 단계, 종료사유)
- 필터(오늘/7일/30일)
- `전체 삭제` 버튼

개인정보 정책:
- 키워드 평문 표시 금지(마스킹)

### S08 접근성 설정
목적:
- 고령/저시력 사용자 지원

컴포넌트:
- 큰 글씨 토글
- 고대비 토글
- 단순 UI 모드 토글

### S09 오류/복구 가이드
목적:
- 실패 상황별 회복 경로 제공

컴포넌트:
- 오류 코드별 설명 카드
- CTA: `권한 설정 열기`, `다시 시도`, `진단 실행`
- 고객 문의 복사용 진단 코드

## 6. 설정 흐름 상세
1. 사용자가 S05에서 토글 변경
2. UI가 낙관적 반영
3. 저장소 저장 결과 수신
4. 성공 시 `반영 완료` 표시
5. 실패 시 원복 + 오류 토스트 + S09 이동 옵션

## 7. 예외 케이스 UX

### 7.1 권한 거부
케이스:
- 마이크 권한 거부

UX 처리:
- 홈 토글 OFF 강제
- 상태 칩 `ERROR`
- 하단 고정 배너: `마이크 권한이 필요합니다`
- CTA: `설정에서 허용`

### 7.2 배터리 세이버 활성
케이스:
- 배터리 <= 20% 또는 OS 배터리 세이버 ON

UX 처리:
- 홈 상단 `절전 감지 모드` 배지 표시
- 설정에서 자동 전환 설명 노출
- 테스트 결과에서 `정확도보다 절전 우선` 안내

### 7.3 백그라운드 제한(Android 14+)
케이스:
- 사용자 액션 없는 자동 리스닝 시작 시도

UX 처리:
- 즉시 실패 대신 `READY_TO_RESUME` 상태
- 고우선 알림 액션 `다시 시작`
- 알림 탭 시 리스닝 재개

### 7.4 통화/오디오 인터럽션
케이스:
- 세션 중 통화 시작 또는 오디오 포커스 영구 상실

UX 처리:
- 세션 즉시 중지
- 로그에 종료 사유 `CALL_INTERRUPTION` 또는 `AUDIO_FOCUS_LOST`
- 홈에 `통화 종료 후 다시 시작` 안내

## 8. 마이크로카피 가이드
- 리스닝 ON: `음성 대기 중입니다.`
- 2단계 대기: `확인 문구를 말해주세요.`
- READY_TO_RESUME: `보안 정책으로 자동 시작이 제한되었습니다. 버튼을 눌러 다시 시작하세요.`
- 권한 거부: `마이크 권한이 없으면 폰 찾기를 시작할 수 없습니다.`

## 9. 접근성/국제화 규칙
- 모든 핵심 버튼 최소 48dp 터치 타깃
- 상태 칩은 색 + 텍스트 동시 제공
- TalkBack 라벨 필수
- 문자열 리소스 분리(i18n-ready)

## 10. UX 검증 시나리오
- [ ] 최초 설치 후 3분 내 리스닝 ON 가능
- [ ] 권한 거부 후 2탭 내 복구 진입 가능
- [ ] Android 14+ 제한 상황에서 알림 액션으로 재개 성공
- [ ] 저전력 모드에서 상태 배지/정책 안내 일관성 유지
- [ ] 세션 로그에 민감 정보 평문 노출 없음
