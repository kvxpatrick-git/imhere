## 2. 권한 정책

### 2.1 필수 권한
| 권한 | 사용 목적 | 사용자 영향 | 거부 시 동작 |
|---|---|---|---|
| RECORD_AUDIO | 웨이크/중지 음성 감지 | 마이크 사용 | 리스닝 시작 불가 |
| FOREGROUND_SERVICE | 백그라운드 리스닝 서비스 유지 | 상시 알림 노출 | 서비스 제한 |
| FOREGROUND_SERVICE_MICROPHONE (Android 14+) | 마이크 유형 FGS 선언 | 정책 준수 필수 | 자동 시작 차단 |
| VIBRATE | Stage3 진동 | 진동 재생 | 사운드만 동작 |

### 2.2 선택 권한
- `POST_NOTIFICATIONS` (Android 13+): 상태/복구 알림 표시. 거부 시 기능은 동작하나 복구 UX가 약화됨.

### 2.3 권한 요청 순서
1. 온보딩에서 마이크 권한 먼저 요청
2. 성공 후 알림 권한 요청
3. 마지막으로 진동 권한 안내
4. 거부 시 즉시 복구 경로(설정 이동 CTA) 제공

### 2.4 권한 철회 대응
- 런타임에서 권한 철회 감지 시 즉시 `LISTENING` 중단
- 상태 `ERROR` 전환 후 사용자 안내
- 복구 완료 시 사용자 액션으로 재시작

## 3. 포그라운드 서비스/알림 정책

### 3.1 서비스 선언
- `foregroundServiceType="microphone"`
- Android 14+에서 사용자 시작 컨텍스트(`userInitiated`) 기반 실행

### 3.2 알림 채널 정책
- 채널명: `Phone Finder Listening`
- 중요도: 기본 `LOW`, 복구 알림 `HIGH`
- 필수 액션:
- `리스닝 중지`
- `다시 시작` (`READY_TO_RESUME` 상태)
- `설정 열기`

### 3.3 자동 시작 제한 대응
- `BOOT_COMPLETED` 시 즉시 리스닝 자동 시작 금지(Android 14+)
- 대신 `READY_TO_RESUME` 상태와 알림 액션 제공
- 사용자 탭 이벤트로만 리스닝 재개

## 4. 보안 설계 원칙
1. 최소 수집: 음성 원본 파일 저장/전송 금지
2. 최소 보관: 세션 로그 30일 TTL
3. 최소 노출: 키워드/중지문구 평문 저장 금지
4. 기본 암호화: 민감 필드는 저장 전 AES-GCM 암호화
5. 키 보호: Android Keystore 기반 키 관리

## 5. 데이터 분류 및 보호 정책

| 데이터 항목 | 분류 | 저장소 | 암호화 | 보존 |
|---|---|---|---|---|
| 웨이크 키워드 | 민감 | Room | AES-GCM 필드 암호화 | 사용자 삭제 시 즉시 |
| 중지 문구 | 민감 | DataStore | AES-GCM | 사용자 삭제 시 즉시 |
| 기능 토글 | 내부 | DataStore | 파일 암호화 | 앱 삭제 시 제거 |
| 세션 로그 | 내부 | Room | 평문(민감값 제외) | 30일 TTL |
| 오류 코드 | 내부 | 로컬 로그 | 평문(식별정보 제외) | 30일 |

보조 정책:
- 로그에는 발화 원문 저장 금지
- 키워드 표시는 해시/마스킹만 허용

## 6. 위협 모델 요약

### 6.1 주요 위협
1. 단말 탈취 후 로컬 DB 열람
2. 디버그 로그를 통한 민감값 노출
3. 백업/복원 과정에서 키 불일치
4. 비정상 종료 시 볼륨 미복원

### 6.2 대응
1. 키워드/문구 암호화 + Keystore 키 보관
2. 민감 로그 차단 + 릴리즈 빌드 로그 레벨 제한
3. 키 로테이션/재생성 정책 문서화
4. 세션 종료 finally 복구 및 복구 실패 오류 코드 기록

## 7. 보안 이벤트/오류 코드
- `E-SEC-001`: Keystore 접근 실패
- `E-SEC-002`: 복호화 실패
- `E-SEC-003`: 암호화 실패
- `E-PRM-001`: Android 14+ 백그라운드 시작 제한
- `E-PRM-002`: 권한 런타임 철회

전달 규칙:
- 사용자 메시지: 친화적 요약
- 내부 로그: 코드 + 스택(PII 제거)

## 8. 개인정보 처리방침(초안)

### 8.1 수집 항목
- 앱은 음성 원본 파일을 수집/저장/전송하지 않습니다.
- 앱은 기능 제공을 위해 다음 로컬 데이터만 저장합니다.
- 키워드 설정(암호화 저장)
- 기능 설정 값
- 폰 찾기 실행 로그(시간, 종료 사유 등)

### 8.2 이용 목적
- 음성 키워드 인식 기반 폰 찾기 기능 제공
- 기능 품질/안정성 유지(오류 코드, 상태 로그)

### 8.3 제3자 제공
- MVP에서는 사용자 데이터를 외부 서버나 제3자에게 제공하지 않습니다.

### 8.4 보관 및 파기
- 세션 로그는 기본 30일 보관 후 자동 삭제됩니다.
- 사용자는 앱 내에서 즉시 로그 전체 삭제를 수행할 수 있습니다.

### 8.5 이용자 권리
- 사용자는 언제든 키워드/설정/로그를 삭제할 수 있습니다.
- 권한 허용/철회는 OS 설정에서 변경할 수 있습니다.

### 8.6 아동 개인정보
- 본 앱은 아동 대상 서비스가 아니며, 별도 아동 개인정보를 수집하지 않습니다.

### 8.7 문의처
- 운영 이메일(예정): `privacy@imhere.app`
- 릴리즈 전 실제 운영 채널로 교체 필요
